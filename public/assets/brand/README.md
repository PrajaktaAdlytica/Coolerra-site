# Coolerra Brand Assets

## Logo masters

- `coolerra-mark-color.svg`: expressive Phase Lens mark with subtle color depth.
- `coolerra-mark-flat.svg`: flat production mark for UI and print.
- `coolerra-mark-monochrome.svg`: single-color mark.
- `coolerra-mark-reversed.svg`: light mark for dark surfaces.
- `coolerra-logo-horizontal.svg`: outlined horizontal lockup.
- `coolerra-logo-horizontal-reversed.svg`: outlined light lockup for dark surfaces.

All SVG wordmarks are outlined and have no font dependency. Standard logo files have transparent backgrounds.

## Favicon markup

```html
<link rel="icon" href="/assets/favicons/favicon.ico" sizes="any">
<link rel="icon" href="/assets/favicons/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/assets/favicons/favicon-32x32.png" sizes="32x32" type="image/png">
<link rel="apple-touch-icon" href="/assets/favicons/apple-touch-icon.png">
<link rel="manifest" href="/assets/favicons/site.webmanifest">
<meta name="theme-color" content="#073B32">
```

Use the flat mark below 48 px. Use the expressive mark at larger brand moments. Keep the aperture facing right and preserve the artwork's built-in clear space. These masters use the exact traced geometry of the approved Phase Lens reference.
